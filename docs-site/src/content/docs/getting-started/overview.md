# caudio

caudio is a headless, local music player and a reusable C++23 library. It
decodes audio with FFmpeg, stores the library and playback state in SQLite,
and exposes a command-line client backed by a daemon.

Start with the [Getting Started hub](/getting-started/), or continue to
[Installation](/getting-started/installation) and [Quick Start](/getting-started/quickstart).
